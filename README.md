# CS2 Aim Trainer

Projeto de treino de mira desenvolvido para jogos competitivos.

## Objetivo

Criar uma ferramenta para praticar:

* Tempo de reação
* Precisão de mira
* Coordenação
* Consistência competitiva

## Tecnologias

* Python
* Game Logic
* Input Handling

## Funcionalidades

* Treino de reflexo
* Simulação de alvos
* Métricas de desempenho
